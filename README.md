# Грани

Конструктор для задач по стереометрии. Берёшь фигуру, строишь на ней то, что обычно рисуют от руки в учебнике, — сечения, перпендикуляры, вписанные и описанные сферы — и крутишь чертёж, чтобы видеть построение «изнутри».

Главное — математическая честность: всё считается точно, ответы получаются в виде дробей и корней (`3√3/4`, `a√6/12`, `12π`), а не округлёнными числами. Крайние случаи — три точки на одной прямой, плоскость мимо фигуры, несуществующая сфера — не ломают программу, а объясняются словами.

**Открыть в браузере: https://flew96.github.io/facets/** — ничего устанавливать не нужно.

## Запуск у себя

Нужен только [Node.js](https://nodejs.org) 18 или новее, зависимостей нет.

```bash
npm start
```

Затем откройте http://localhost:5173.

Тесты:

```bash
npm test
```

Проверка кода (нужен один раз `npm install` — ставит только ESLint для разработки, самому приложению зависимости не нужны):

```bash
npm run lint
```

Тесты и проверка запускаются в GitHub Actions на каждый push.

## Фигуры

- **Многогранники:** куб, прямоугольный параллелепипед, призма (прямая и наклонная), пирамида, правильный тетраэдр, усечённая пирамида.
- **Основания призм и пирамид:** правильные треугольник, квадрат и шестиугольник; прямоугольный треугольник, прямоугольник, ромб, равнобедренная трапеция; произвольный треугольник по трём сторонам; произвольный выпуклый многоугольник по координатам вершин.
- **Вершина пирамиды** проецируется в центр основания, в любую его вершину или в произвольную точку (x; y).
- **Тела вращения:** цилиндр, конус, усечённый конус, шар.

Размеры вводятся точно — `3/2`, `2√3`, `sqrt(2)` — или ползунком. Для многогранников размер можно задать буквой: с ребром `a` ответы получаются в общем виде, например `3a²√3/4`.

## Построения

- **Точки** на вершинах, рёбрах (в нужном отношении), гранях, центры граней, точка пересечения медиан треугольника, точка пересечения прямой и плоскости. Клик по ребру привязывается к «хорошим» отношениям — ½, ⅓, ¼…
- **Сечения:** через три точки, параллельно плоскости, перпендикулярно прямой. Плоскость можно выбрать одним кликом по грани или по готовому сечению. Программа сама находит многоугольник сечения, его форму, площадь, периметр и объёмы обеих частей.
- **Метод следов по шагам:** сечение строится так, как его строят в тетради — прямые в гранях, пересечения с продолжениями рёбер, вспомогательные точки.
- **Перпендикуляры:** из точки на плоскость, на прямую, общий перпендикуляр к скрещивающимся прямым.
- **Сферы:** вписанная и описанная. Если сферы нет, программа объясняет почему, с конкретными числами.
- **Измерения:** расстояния, углы между прямыми, прямой и плоскостью, двумя плоскостями.
- **Решение методом координат** под каждым результатом: координаты, векторы, формулы с подстановкой.

## Чертёж

- Параллельная проекция, как в учебнике; невидимые линии пунктиром.
- Вращение мышью, масштаб колесом, прозрачность граней.
- Сечение в натуральную величину, развёртка поверхности с линиями сечений.
- «Отсечь часть фигуры» — убрать одну из частей и заглянуть внутрь.
- Готовые примеры задач, сохранение задачи в файл, ссылка на задачу, экспорт чертежа в SVG.

## Как устроено

| Папка | Что внутри |
|---|---|
| `src/math` | Точная арифметика на `BigInt`: рациональные числа и квадратные корни, точный знак и деление, упрощение вложенных радикалов, π как символ |
| `src/geom` | Фигуры, построения, метод следов, решения методом координат, тела вращения |
| `src/ui` | Чертёж в SVG, интерфейс, развёртка, примеры; `state.js` — проверка задачи из ссылки или файла и упаковка в ссылку |
| `tests` | Тесты на классических задачах с известными ответами; каждый пример из списка; ссылки и файлы задач |

Числа с плавающей точкой используются только для рисования; все ответы считаются точно.

## Ограничения

- Многогранники только выпуклые; правильного пятиугольника нет — его координаты не выражаются квадратными корнями из рациональных чисел.
- Наклонные сечения тел вращения (эллипс, парабола, гипербола) не поддержаны — программа об этом сообщает.
- Буква в размерах работает только для многогранников; у тел вращения размеры задаются числами.
- Для тел вращения нет развёртки и «отсечь часть».
